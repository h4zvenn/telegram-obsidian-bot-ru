# telegram-obsidian-bot

Telegram-бот для быстрых заметок в Obsidian: принимает текст и голосовые сообщения, распознаёт речь локально, исправляет текст через локальную LLM и сохраняет итоговую заметку в папку `inbox` вашего Obsidian vault.

## Что умеет

- Принимать обычные текстовые сообщения.
- Принимать голосовые сообщения из Telegram.
- Распознавать русскую речь локально через `faster-whisper`.
- Исправлять орфографию, пунктуацию и типичные ошибки распознавания через Ollama.
- Сохранять итоговые заметки в Markdown для Obsidian.
- Показывать последние заметки через inline-кнопки в Telegram.
- Поддерживать режимы обычной заметки, плана и сохранения без ИИ.

## Как это работает

Схема обработки:

```text
Telegram message / voice
→ bot.py
→ voice.py (только для голосовых)
→ ai.py
→ Markdown note
→ Obsidian vault / inbox
```

Для голосовых сообщений бот:

1. Скачивает `.ogg` из Telegram.
2. Передаёт файл в `faster-whisper`.
3. Получает расшифровку текста.
4. Отправляет текст в локальную модель через Ollama.
5. Сохраняет заметку в `inbox`.

## Требования

Нужно установить и настроить:

- Python 3.11+.
- Telegram Bot Token.
- Ваш Telegram user ID.
- [Ollama](https://ollama.com/) с локальной моделью `qwen3:8b`.
- FFmpeg, если нужен стабильный аудиостек для обработки голосовых.
- Obsidian vault с папкой `inbox` или доступом на её создание.

## Установка

### 1. Клонируйте репозиторий

```powershell
git clone https://github.com/h4zvenn/telegram-obsidian-bot.git
cd telegram-obsidian-bot
```

### 2. Создайте виртуальное окружение

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установите зависимости

```powershell
pip install -r requirements.txt
```

### 4. Подготовьте `.env`

Скопируйте пример:

```powershell
copy .env.example .env
```

Заполните значения в `.env`:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_USER_ID=123456789
OBSIDIAN_VAULT=C:\ObsidianNotes
```

### 5. Установите Ollama и модель

Запустите Ollama и скачайте модель:

```powershell
ollama pull qwen3:8b
```

Потом поднимите локальный сервер Ollama:

```powershell
ollama serve
```

По умолчанию бот ожидает API Ollama по адресу:

```text
http://127.0.0.1:11434
```

## Запуск

В одном окне PowerShell:

```powershell
ollama serve
```

В другом окне:

```powershell
cd "C:\Users\offku\Projects\telegram-obsidian-bot"
.\.venv\Scripts\Activate.ps1
python -u bot.py
```

Если всё настроено правильно, бот начнёт принимать сообщения и сохранять заметки в ваш vault.

## Команды

- `/start` — показать главное меню.
- `/help` — показать меню и краткую помощь.
- `/id` — показать ваш Telegram user ID.
- `/raw текст` — сохранить текст без обработки ИИ.
- `/plan текст` — оформить текст как список действий.

## Голосовые сообщения

Голосовые сообщения распознаются локально через `faster-whisper`.

Что важно:

- Чем чище диктовка, тем лучше результат.
- Для русской речи используется фиксированный `language="ru"`.
- После распознавания текст дополнительно проходит редактуру через локальную модель.
- В заметку может добавляться исходная расшифровка внизу для проверки.

## Меню и кнопки

В Telegram-боте доступны inline-кнопки:

- `📥 Последние заметки` — показать несколько последних `.md` файлов из `inbox`.
- `ℹ️ Помощь` — показать основные команды.
- Кнопки навигации назад к списку и в главное меню.

## Что сохраняется в заметку

Итоговый Markdown-файл обычно содержит:

- дату и время создания;
- исправленный текст;
- до трёх тегов, если их вернул ИИ;
- исходную расшифровку в callout-блоке, если заметка прошла через ИИ.

## Безопасность

Никогда не коммитьте в Git:

- `.env`
- `.venv/`
- `models/`
- локальные веса моделей
- временные аудиофайлы
- токены и приватные ключи

Если токен Telegram случайно попал в историю чата, лог или репозиторий, его нужно немедленно перевыпустить через `@BotFather`.

## Типичные проблемы

### Кнопки в Telegram не реагируют

Проверьте, что бот запущен с обработкой `callback_query` и не ограничен только `message` updates.

### Голосовые не распознаются

Проверьте:

- установлен ли `faster-whisper`;
- импортируется ли `voice.py` без ошибок;
- доступен ли FFmpeg, если он нужен вашей среде;
- хватает ли памяти для модели.

### ИИ не отвечает

Проверьте:

- запущен ли `ollama serve`;
- скачана ли модель `qwen3:8b`;
- доступен ли `http://127.0.0.1:11434`.

### Заметки не сохраняются

Проверьте:

- существует ли путь из `OBSIDIAN_VAULT`;
- есть ли права записи;
- создаётся ли папка `inbox`.
